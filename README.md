# Loan Payment Project

A Python application developed to calculate loan payments using financial inputs and mathmematics

## Features

- Caculate loan payments using financial inputs.
- Process loan data from CSV and text files.
- Generate and store calculation results.
- Perform financial calculations using python

## Files

- 'loan_payment.py' - Main program for calculating loan payments.
- 'coin.py' - Coin-related programming exercise.
- 'loans.csv' - Laon data used by the program.
- 'loans.txt' - Text-based loan data.
- 'loan_results.txt' - Results generated by the program.

## Technologies

- Python
- CSV and text file processing
- Git
- Github

This project was developed as part of my programming studies. It demonstrates the use of Python.
